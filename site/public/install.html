INSTALLATION GUIDE

Before you install

Coddle 0.2.1 is an early macOS preview, available free under MIT. This download includes the app for both Apple Silicon and Intel.

This preview is ad-hoc signed. It is not Developer ID signed or notarized by Apple. macOS may block it from opening. If you prefer a notarized app, wait for a future release. Review the source and the notes below before deciding to use this preview.

Download DMG preview ↗

Version 0.2.1 · Build 3 · Universal

Will it work on my Mac?

The app is built with a macOS 13 minimum deployment target. That build target does not mean every feature is available on every Mac. Coddle checks the battery, native charge-limit support, and lid capabilities at runtime.

Current real-device validation covers Apple Silicon on recent macOS. Intel and macOS 13 runtime testing, the complete lid and external-display device matrix, and full VoiceOver validation remain open. Sleep prevention and battery display are separate from native charge-limit support.

Install and choose your routine

  1. Download Coddle-0.2.1-universal.dmg from GitHub, open it, then drag Coddle onto the Applications shortcut on the right.
  2. Open Coddle. If macOS blocks it because it cannot verify the developer, stop and review your choice; this download does not include Apple notarization.
  3. In the setup window, choose your charging routine and whether long tasks should keep running. Coddle checks the result when it applies a power setting.
  4. Use the menu bar to change your plan. You can reopen the setup guide from Settings, or quit the app from its panel.

Which permissions are needed?

Charge control and ordinary prevention of automatic sleep do not require a privileged helper, Accessibility access, or Screen Recording access. Notifications and launch at login are optional choices.

Running with the lid closed requires Coddle’s optional helper and a macOS administrator approval. The helper installs only when you explicitly select Install in setup or Settings. Installing it does not itself turn on lid-closed operation. A system power-mode change can also require administrator authorization.

When you turn Sleep Prevention off, Coddle stops its Mac, display, and lid-closed controls while keeping your display and lid preferences for next time. If a stop cannot be confirmed, the app keeps that state visible. Turn off lid-closed operation before explicitly putting the Mac to sleep.

Inspect the download

Compare the DMG against the published SHA-256 checksums. These identify the bytes of this preview; they do not replace Apple signing or notarization. The GitHub release links the version to its source tag and download assets.

The tagged source contains the macOS app, the MIT license, and build instructions. Building requires a Mac with Apple development tools. Version 0.2.1 fixes retained dropdown-menu callbacks after a menu closes.

Updating Coddle

Version 0.1.0 needs one manual upgrade to this release. After that, use Settings → General → Software Update to check for updates, or enable automatic checks. Automatic download and installation is a separate option; installation normally completes when Coddle quits.

安装指南

安装前须知

Coddle 0.2.1 是免费的 macOS 早期预览版，采用 MIT 许可。下载包同时包含 Apple Silicon 和 Intel 版本。

本预览版采用临时签名，尚未使用 Developer ID 签名，也未经过 Apple 公证。macOS 可能会阻止打开。如果你希望使用经过公证的应用，可以等待后续版本。请在决定使用前阅读源码和以下说明。

下载 DMG 预览版 ↗

版本 0.2.1 · Build 3 · Universal

我的 Mac 可以使用吗？

应用以 macOS 13 作为最低构建目标。这不代表每台 Mac 都能使用所有功能。Coddle 会在运行时检查电池、原生限充和合盖功能的支持情况。

当前真机验证覆盖近期 macOS 上的 Apple Silicon。Intel 与 macOS 13 真机测试、完整的合盖及外接显示器设备覆盖、完整 VoiceOver 验证仍待完成。防止休眠、电池状态展示与原生限充是不同的能力。

安装并选择你的使用习惯

  1. 从 GitHub 发布页下载 Coddle-0.2.1-universal.dmg，打开后将左侧 Coddle 拖入右侧“应用程序”快捷方式。
  2. 打开 Coddle。如果 macOS 因无法验证开发者而阻止打开，请先停下来重新评估是否使用；此下载包尚未经过 Apple 公证。
  3. 在引导窗口中选择充电习惯，以及是否让长任务持续运行。Coddle 应用电源设置后会检查实际结果。
  4. 日后可从菜单栏调整计划，也可以从“设置”重新打开使用引导，或在面板中退出应用。

需要哪些权限？

限充和普通防止自动休眠不需要特权辅助组件，也不需要辅助功能或屏幕录制权限。通知和登录时启动均由你选择。

合盖后继续运行需要可选辅助组件，以及 macOS 管理员授权。只有你在引导或设置中明确选择“安装”，组件才会安装；安装本身不会开启合盖运行。切换系统电源模式也可能需要管理员授权。

关闭“防止休眠”时，Coddle 会停止它管理的电脑、屏幕及合盖保活，并保留屏幕与合盖偏好，供下次使用。若无法确认停止结果，应用会持续显示该状态。主动让 Mac 进入睡眠之前，请先关闭合盖运行。

核对下载内容

你可以使用公开的 SHA-256 校验值核对 DMG 内容。校验值用于确认文件字节，并不代替 Apple 签名或公证。GitHub 发布页提供版本对应的源码标签和下载文件。

版本标签对应的源码包含 macOS 应用、MIT 许可证和构建说明。自行构建需要 Mac 和 Apple 开发工具。0.2.1 修复了下拉菜单关闭后回调未释放的问题。

更新 Coddle

0.1.0 用户需要先手动安装一次此版本。之后可从“设置 → 通用 → 软件更新”检查更新，或开启自动检查。自动下载并安装是单独的选项，安装通常在 Coddle 退出时完成。
